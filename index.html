Abstract

Mozilla Firefox is a free, open-source web browser and one of only three browsers with its own major rendering engine. This site researches Firefox as a component of the World Wide Web: how it grew out of Netscape, what makes its technology and mission different, where it stands in the market today, and the future it has as companies integrate AI features.

Key Terms

  • Firefox: the web browser made by Mozilla, first released as version 1.0 in 2004.
  • Mozilla: the nonprofit foundation and the corporation that build Firefox.
  • Gecko: Firefox's rendering engine, which turns HTML and CSS into pixels.
  • Open source: software whose code anyone can read, modify, and share.
  • Browser wars: the competition for market share, first between Netscape and Microsoft.

Abstract

A web browser is the client software that turns a web address into an interactive page. This site researches the browser as one technical component of the World Wide Web: what it does, how it evolved from a single research tool at CERN into a global platform, where the market stands today, and where it may go next, including AI-assisted and agentic browsing. It is built in stages across three milestones; this first milestone sets up the site structure.

Key Terms

  • Browser: software that requests, renders, and runs web content.
  • Rendering engine: the code that turns HTML and CSS into pixels (Blink, WebKit, Gecko).
  • DOM: the in-memory tree of a page that scripts can read and change.
  • Browser wars: the competition for market share, first between Netscape and Microsoft.
  • Agentic browsing: an AI assistant that completes tasks on the web for the user.

Key Concepts

Seven core ideas behind how browsers work.

1. Rendering Engine

The component that turns HTML and CSS into what you see. Blink, WebKit, and Gecko are the three in use today.

2. DOM

The Document Object Model is a tree built from the HTML. Scripts read and change it to update the page.

3. JavaScript Engine

Runs a page's scripts. Chrome's V8 made scripting much faster and helped enable web apps.

4. HTTP and TLS

The browser fetches pages over HTTP and protects the connection with TLS (HTTPS).

5. Same-Origin Policy

A security rule that stops a page from freely reading data belonging to another site.

6. Sandboxing and Multi-Process

Each tab runs in its own restricted process, so a crash or exploit stays contained.

7. Web Standards

Specifications from the W3C and WHATWG, such as HTML, CSS, and the DOM, let one page work in any browser.

Key Concepts

Seven core ideas behind Firefox.

1. Gecko Engine

Firefox's rendering engine, which turns HTML and CSS into the page you see. It is one of three major engines.

2. Open Source

Firefox's code is public under the Mozilla Public License, so anyone can inspect and contribute to it.

3. WebExtensions

The add-on system that lets developers extend the browser with tools such as ad blockers and password managers.

4. Enhanced Tracking Protection

Built-in blocking of known trackers, turned on by default since 2019.

5. Multi-Process Architecture

Web pages run in separate processes from the browser interface, so a crash or exploit stays contained.

6. Release Channels

Firefox ships as Release, Beta, and Nightly builds, plus an Extended Support Release for organizations.

7. AI Controls

Settings that let users manage or fully block AI features, added in Firefox 148.
